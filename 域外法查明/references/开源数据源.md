# 开源法律数据源指南

> v2.0 新增。本文件介绍三类开源数据层：git 版本化法律库、开放数据采集清单、MCP 服务器集群。
> 定位：**核验与深挖**——用于效力核验、历史版本比对、批量数据端点发现和结构化检索，**不替代官方来源的最终确认**。
> 访问 GitHub 克隆在中国大陆网络环境下可能需要代理。

---

## 一、选用矩阵：什么时候用哪个

| 需求场景 | 首选 | 说明 |
|----------|------|------|
| 查某法条在特定历史日期的版本 | 🟣 lexifina | 点查法 `law.py show <日期> <路径>`，一步到位 |
| 核验法条修订/废止轨迹 | 🟣 lexifina | `law.py blame` / `law.py diff` 逐条溯源每个修订来源 |
| 核验判例是否仍为良好法 | 🟣 lexifina `check_precedent` / 官方引证系统 | 列出适用该条文的判决并比对文本是否仍有效 |

## 二、🟣 git 版本化法律库：lexifina/global-law

**仓库**：<https://github.com/lexifina/global-law>（索引层 CC0；各国法律文本在各 `lexifina/<country>-law` 仓库，遵循其自身条款）
**原理**：每个法域一个 git 仓库，**每个 commit 就是一部法律生效**——因此可以回答"某国法律在任意日期是什么样的"，以及"每个字是哪部法律写下的"。

### 覆盖

- **立法**：多国联邦/国家/州/市层级（如 `germany/bund/acts/`、`brazil/bahia/acts/`）
- **判例**（一案一文件、一判一 commit，按判决日计）：
  - 美国：最高法院 + 各巡回上诉法院（ca1–ca11、cadc、cafc），源自 Caselaw Access Project (CC0)
  - 德国：BVerfG、BVwG、BFH、BAG、BPatG，按 ECLI/Aktenzeichen 归档
  - 法国：Cour de cassation、上诉法院、Conseil d'État、Conseil constitutionnel（DILA 开放数据，Licence Ouverte 2.0）
  - 瑞士：联邦法院 + 各州法院
  - 荷兰：Hoge Raad 等全部层级法院，按 ECLI 归档
  - 波兰：最高法院、宪法法院等（SAOS，判决不在版权保护内）
  - 芬兰（Finlex，CC BY 4.0）、奥地利（RIS，CC BY 4.0）
- **引证解析**：支持 ECLI（`ECLI:NL:HR:2019:1234`）、瑞士案号（`4A_123/2024`）、BGE 引证（`BGE 142 II 307`）、法国 pourvoi（`n° 18-12.345`）、QPC（`n° 2019-791 QPC`）、DILA id、德国 Aktenzeichen（`1 BvR 123/20`）及法条缩写（`§ 823 Abs. 1 BGB`、`§§ 280, 281 BGB`、`artikel 6:162 BW`、`article 1240 du code civil`、`Art. 336 OR` 等）

### 安装与常用命令

```bash
# 浅克隆索引（不含各国完整历史，体积小）
git clone --depth 1 https://github.com/lexifina/global-law && cd global-law

# 按需添加语料库（每个国家数 GB，勿全量添加）
python3 tools/countries.py add united-states/federal/usc     # 美国法典
python3 tools/countries.py add germany/caselaw               # 德国判例
# 判例语料库不随国家一起添加，需单独 add

# 点查法：某日期有效的法条（Windows 下用 py 或 python 代替 python3）
python3 tools/law.py show 2022-05-01 united-states/federal/usc/title-11/1182.md
# 溯源：该法条每行文字的立法来源
python3 tools/law.py blame 2022-07-01 <路径>
# 比对：两个日期之间改了什么
python3 tools/law.py diff 2022-05-01 2022-07-01 <路径>
# 时间窗内生效的法律清单
python3 tools/law.py laws 1990-01-01 1990-12-31 germany
```

> ⚠️ 不要用 `--depth` 克隆单个国家仓库——日期信息读取自完整历史；`countries.py add` 会自动拉取全量。

### MCP 接入（18 个只读工具）

`tools/mcp_server.py` 是本地 MCP 服务器（仅需 Python 3.9+ 与 git，运行时零网络请求），功能含：find_provision、read_law（按日期读条文）、words/blame、diff、check_precedent（判例适用与现行有效性比对）、resolve_citations、search 等。克隆目录已内置 Claude Code / Cursor / VS Code / Codex 配置，打开文件夹即生效。其他客户端：

```json
{ "mcpServers": { "global-law": { "command": "git", "args": ["-C", "/path/to/global-law", "-c", "alias.global-law-mcp=!sh tools/mcp.sh", "global-law-mcp"] } } }
```

完整工具清单见仓库 [MCP.md](https://github.com/lexifina/global-law/blob/main/MCP.md)；数据新鲜度见 [FRESHNESS.md](https://github.com/lexifina/global-law/blob/main/FRESHNESS.md)。

## 三、⚙️ 开放数据采集清单：worldwidelaw/legal-sources

**仓库**：<https://github.com/worldwidelaw/legal-sources>（开源脚本，开放数据定位）
**规模**：110+ 国家、960+ 采集脚本；Dashboard 与检索 API：<https://legaldatahunter.com>（已索引 1600 万+ 法律文档）

### 两种用法

**用法 1：当作"各国官方数据端点目录"用（推荐，无需跑代码）**

`sources/{国家代码}/{数据源名}/` 的目录结构本身即为答案——每个子目录对应一个国家的官方门户/API/bulk 端点，`config.yaml` 记录访问方式与限速，`README.md` 介绍数据源。查"某国官方数据从哪批量获取"时，先浏览对应国家目录。

```
sources/
  FR/LegifranceCodes/        # 法国整合法典（API）
  DE/GesetzeImInternet/      # 德国联邦法律（bulk XML）
  IT/NormattivaLegislation/  # 意大利立法（API）
  ES/BOE/                    # 西班牙官方公报（API）
  ...
```

**用法 2：运行采集脚本（开发者向）**

```bash
git clone https://github.com/worldwidelaw/legal-sources.git && cd legal-sources
pip install -r requirements.txt
python runner.py status          # 项目状态
python runner.py sample FR/LegifranceCodes   # 测试某数据源（取样 10+ 文档）
```

每个脚本归一化输出到统一 schema（`_id/_source/_type[legislation|case_law]/title/text/date/url`），区分**立法**（可变，upsert + 版本追踪）与**判例**（不可变，append + 去重）两种数据模型。

**覆盖概览**：欧盟 27 国 130+ 源、EFTA/EEA 10+、欧洲委员会国家 20+、西巴尔干 15+、拉美 25+、亚太 30+、中东非 20+、其他 15+。

**在线检索 API**：legaldatahunter.com 提供 1600 万+文档的统一检索，可作为跨法域关键词补充发现工具（结果须回官方来源核验）。

## 四、🔌 MCP 服务器集群：Ansvar-Systems

**组织**：<https://github.com/Ansvar-Systems>（瑞典 Ansvar Systems 维护，服务器 Apache-2.0，语料库经其基础设施托管）
**规模**：100 个法律 MCP 仓库，经统一网关接入：**<https://gateway.ansvar.eu/mcp>**（OAuth 注册，有免费档；每个结果附逐字来源引证）

### 覆盖

| 类别 | 覆盖 |
|------|------|
| 国家法（28 法域，以欧洲为主） | UK、德国、法国、意大利、西班牙、葡萄牙、荷兰、比利时、卢森堡、爱尔兰、奥地利、瑞士、波兰、捷克、斯洛伐克、匈牙利、罗马尼亚、保加利亚、克罗地亚、斯洛文尼亚、爱沙尼亚、拉脱维亚、立陶宛、芬兰、瑞典、丹麦、冰岛、马耳他、列支敦士登等 |
| EU 法 | comprehensive-eu-law-mcp、EU_compliance_MCP |
| 专题库（按国家） | 金融监管（德西奥芬匈等 14 国）、数据保护（英意西比瑞等 20+ 国）、网络安全（英意荷西奥等 14 国）、医疗、关键基础设施、供应链安全、德国竞争法等 |

### 接入（一行命令）

```bash
# Claude Code
claude mcp add ansvar --transport http https://gateway.ansvar.eu/mcp
```

```json
// Claude Desktop / Cursor / 通用 MCP 客户端
{ "mcpServers": { "ansvar": { "type": "url", "url": "https://gateway.ansvar.eu/mcp" } } }
```

首次请求触发 OAuth 注册流程（快速入门：<https://ansvar.eu/docs/quickstart>）；档位（free/premium/team/company）决定配额与可达的下游 MCP。

> ⚠️ 语料库**不在仓库内再分发**（上游 TDM 与标准许可限制），各仓库提供自行构建语料的 ingestion 脚本。使用网关即接受其服务条款；对司法用途的关键条文，仍须回官方公报核验。
